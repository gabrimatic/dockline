Dockline

Rest the pointer on a Dock icon and see every window of that app, sharp, even the ones Stage Manager has parked.

Download View on GitHub

What it does

Window previews for the Dock and a window switcher on Option-Tab, in Liquid Glass, for anyone who keeps many windows open or works in Stage Manager.

Dock previews

Rest the pointer on a Dock icon and a glass panel shows every window of that app.

Sharp with Stage Manager

Dockline keeps a picture of each window while it is in front, so parked windows stay sharp.

Live cards

A window on screen at full size stays up to date while its card is open.

Window switcher

Hold Option and press Tab to move through every window, most recent first.

Actions on the card

Close, minimize or full screen from the card, and hide or quit the app.

Pause

From the menu bar, Settings, Control Center, Shortcuts, or with a Focus filter.

Install

Free and open source, for macOS 26 or later on Apple silicon.

curl -fsSL https://raw.githubusercontent.com/gabrimatic/dockline/main/install.sh | bash

It checks the download's SHA-256 before it installs anything. Or download the disk image and see First Open: release builds are signed ad hoc, not notarized.

Privacy

Dockline makes no network requests. Pictures stay in memory and never reach the disk, and password managers are never captured. It needs Accessibility and Screen Recording.
